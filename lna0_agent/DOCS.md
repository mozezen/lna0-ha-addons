# LNA0 Agent

## Configuration

- `control_plane_url`: HTTPS URL for the LNA0 Control Plane.
- `house_id`: LNA0 house identity, for example `LNA0-H-000001`.
- `node_id`: LNA0 node identity, for example `LNA0-N-000001`.
- `hostname`: node hostname, for example `lna0-n-000001`.
- `enrollment_token`: one-time token generated by the Control Plane.
- `heartbeat_interval_seconds`: heartbeat interval, 30 to 300 seconds.
- `control_plane_ca_pem`: optional CA PEM for a private/internal Control Plane certificate.
- `allow_insecure_dev_http`: development-only override. Keep `false` for real nodes.

After successful enrollment, the Agent stores the node credential in `/data/lna0-agent-state.json` with `0600` permissions and attempts to clear `enrollment_token` from its own add-on options through the Supervisor API.
